# 系统结构（第 1 步基线）

```text
电脑浏览器中的模拟手表界面（Vue）
              ↓ HTTP / WebSocket（第 2 步）
统一后端接口（FastAPI，第 2 步）
      ↓               ↓
案例与运行记录      三个模型适配器
（SQLite）          1. 跌倒检测
                    2. 规律/异常检测
                    3. 活动识别
```

## 为什么这样拆分

- 前端只负责“让人看懂”，不直接塞入训练代码。
- 后端统一三个模型的输入输出，避免每个模型各说一套格式。
- 模型通过适配器接入；以后替换模型，不需要重写整个界面。
- 数据来源和模型 manifest 单独保存，答辩时可以逐项追溯。

## 当前进度

只有 Vue 前端空壳和文档已建立。图中的后端、数据库、模型适配器均为下一阶段设计，不代表已经实现。
