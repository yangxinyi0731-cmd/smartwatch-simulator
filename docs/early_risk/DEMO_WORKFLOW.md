# 演示工作流与模型说明（手表 + 工作台）

更新时间：2026-10-07。适用：校赛现场演示 / demo 视频拍摄。

## 一、手表上的四个模型分别是什么、怎么算、在哪看

工作台里运行四个研究模型，结果**分开显示，不合成“综合风险分”**。其中前三个与手表实时数据有关：

| 模型 | 怎么工作 | 最少需要多久数据 | 产出 | 网页位置 | 手表显示 |
|---|---|---|---|---|---|
| 动作识别 | 用公开腕部数据（CAPTURE-24）训练的工程化活动模型，对滚动窗口分类 | 20 秒 | 当前动作候选标签（走路/坐下/进食/睡眠或躺卧…） | 滚动筛查第 1 行“当前动作候选” | 绿字前缀，如 `走路·…` |
| 跌倒动作筛查 | 把最近约 30 秒切成一秒级小片段，与公开受控跌倒数据（WEDA）特征比对，逐片算匹配度，超过阈值算一个“候选窗口” | 1 秒可跑，20 秒后更稳 | 未发现/发现跌倒候选；最高匹配度；**候选窗口数 N** | 第 2 行“跌倒动作筛查”+ 顶部红色横幅 | **红屏** `跌倒候选 N 个` + **振动一次** |
| 提前风险（1/2/3 秒） | 公开数据的“失稳前 1/2/3 秒”窗口训练出的代理模型，输出三个时间点有无风险线索 | 1 秒 | 1/2/3 秒“有/无线索” | 第 3 行“提前风险线索” | 绿字 `·风险1秒`（取最早出现线索的时间点） |
| 日常规律/异常 | 100 天合成事件规律模型（与手表实时无关，用于案例回放） | — | 异常日/事件 | 案例库“日常规律”分类回放 | 不涉及手表 |

说明：`跌倒候选 N 个` 里的 N 是“最近 30 秒里像跌倒动作的片段数量”，不是“摔了 N 次”。候选是“筛查提示”，不是现实报警。

## 二、演示当天完整工作流

### 阶段 0 · 开场前 5 分钟检查
1. 手表电量 ≥ 50%；手机热点开 2.4 GHz；电脑与手表在同一热点（或直接插线）。
2. 打开平台：`http://127.0.0.1:8010/` → 左侧“手表实时”。
3. 选数据来源（USB 串口 / Wi-Fi 无线）→ 点“开始实时读取”。
4. 确认三件事：状态“已连接”、采样速率 ≈ 50 次/秒、手表状态有电量与地址。
5. 轻轻晃一下表：网页波形要跟着动，20 秒后滚动筛查出现动作候选。
6. 录屏/投屏调整：浏览器 Ctrl+加号 放大字号。

### 阶段 1 · 开场（30 秒）
- 一句话定位：**基于公开腕部数据 + 自主采集 + 真机实时**的早期风险研究工作台。
- 指着首屏统计讲：105 组公开数据、30 组自主采集、手表实测记录。

### 阶段 2 · 案例回放（2 分钟）
- 打开一条公开跌倒案例 → 点“开始检测” → 六步流程跑完（检查数据→统一标准→识别动作→筛查跌倒→提前风险→生成分析）。
- 看结论 + 波形依据 + 判断依据块。
- 台词：“每一步都有依据；三个模型独立输出，不合成模糊分数；这是工程研究演示。”

### 阶段 3 · 手表实时（3 分钟，重头戏）
1. 手表戴在手腕上（无线模式，离电脑 0.5 米以上）；
2. “开始实时读取” → 正常走几步（波形平稳）；
3. **抬起手臂快速晃动几下** → 同时看三处：
   - 网页顶部出现红色横幅“发现 N 个跌倒候选窗口”；
   - 手表**红屏**“跌倒候选 N 个”并**振动一次**；
   - 滚动筛查第 2 行给出匹配度与候选数。
4. 停下等 10 秒左右 → 候选清零 → 台词：“刚才那几秒的可疑片段已经滑出窗口，所以清零了。”
5. 指第 3 行“提前风险线索”和手表绿字（`…·风险1秒` / `…·无线索`）→ 台词：“这才是提前预测的部分——提前 1 到 3 秒给出线索。”
6. 双向控制：网页“手表控制”→ 发一句文字到手表屏幕；再点“振动提示”。

### 阶段 4 · 现场采集（1 分钟，可选但推荐）
- 走一条 / 坐一条：开始实时读取（无线）→ 做动作 20–30 秒 → 停止 → 保存本次实时数据 → 登记为案例（类型“真人佩戴动作”，动作对应）。
- 打开“样本总览”点开刚登记的记录 → 台词：“这是刚现场采的，编号 P01-…，可回放复核。”

### 阶段 5 · 新数据检测（1 分钟）
- 把任意 CSV 拖进“新数据检测” → 开始分析 → 同一套六步流程出结果 → 台词：“任何新的传感器文件都能跑这整套流程。”

### 阶段 6 · 收尾与边界（30 秒）
- “所有结果都是工程研究演示：不发送真实报警、不做医疗承诺、不代表真实老人跌倒预测能力。”

## 三、演示中的小状况与对策

| 状况 | 对策 |
|---|---|
| 手表一直红屏+震动 | 取消勾选“把筛查结果同步到手表”，或点“停止” |
| 无线数据慢/卡 | 手表离电脑远一点（别贴数据线）；电量低就插线充电 |
| 网页一直“未连接” | 先“停止”再“开始实时读取”；USB 时确认串口没被录制工具占用 |
| 红屏出现但想继续演示 | 正常现象；快速晃动本来就会触发候选，等它自动清零 |
