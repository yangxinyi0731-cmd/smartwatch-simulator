# 新数据检测格式 v1

校赛版检测台接受 `.csv` 或 `.json` 六轴腕部传感器文件。上传文件只在内存中分析，不自动写入案例库。

## 最简单的 CSV

第一行必须完全是：

```csv
time_s,ax,ay,az,gx,gy,gz
```

从第二行开始，每行一个采样点：时间单位为秒；`ax/ay/az` 是三轴加速度；`gx/gy/gz` 是三轴角速度。页面上传时可选择加速度是 `m/s²` 或 `g`，角速度是 `rad/s` 或 `deg/s`。系统随后统一到 50 Hz、`m/s²`、`rad/s`。

至少需要连续 1 秒、50 个有效采样点；跌倒动作筛查需要至少 4 秒；活动识别需要至少 20 秒。建议每组采集 20–30 秒。

## JSON

```json
{
  "units": {"acceleration": "m/s2", "gyroscope": "rad/s"},
  "samples": [
    [0.00, 0.1, 0.2, 9.7, 0.01, 0.02, 0.03],
    [0.02, 0.1, 0.2, 9.8, 0.01, 0.02, 0.03]
  ]
}
```

每个数组必须依次是 `[time_s,ax,ay,az,gx,gy,gz]`。
