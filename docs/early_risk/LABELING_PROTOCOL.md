# 预事件标签与双人裁决协议（P1 v1）

## 1. 当前适用范围

本协议是未来受伦理与许可批准后的标签合同。P0–P2 不接入真实老人、视频、照护记录或医疗记录；当前测试只使用明确标记为 `ENGINEERING_FIXTURE` 的确定性夹具。

## 2. 裁决准备

1. 先固定目标合同版本和哈希，再打开待裁决事件；
2. 统一设备、视频/观察日志和事件日志时钟，保存同步误差上界；
3. 给两名裁决者分配不同去标识化 ID；
4. 隐藏模型分数、阈值和预测结果，避免标签被模型反向影响；
5. 核对同意、访问和视频用途是否覆盖本次裁决。

## 3. 独立双人裁决

两名裁决者分别标注：

- 事件类型；
- `t_instability`；
- 可选 `t_impact`；
- `t_recovery_or_assist`；
- 标签来源；
- 置信等级；
- 不确定或无法判断原因。

两人第一次提交前不得互看结果。分歧超过预注册时间容差或事件类型不一致时，交给第三名裁决者；不能取平均时间或由模型成绩决定。

## 4. 时间锚点规则

- `t_instability` 选择最早可明确判断平衡被破坏的时刻，而不是撞击峰值；
- `t_impact` 与撞击/着地对应；近跌倒和失稳必须为空；
- `t_recovery_or_assist` 必须晚于失稳和撞击；
- 同步误差上界超过 100 ms 的片段不得进入数秒级研究结论；
- 后续修改锚点必须保留原值、修改者、原因、协议版本和时间戳，不能覆盖历史。

## 5. 困难负样本与设备伪迹

快速坐下、主动躺下、一般姿态转换、绊倒后自主恢复和设备伪迹分别标注。摘表、松动、碰撞、充电、断流、时间倒退或换设备不能并入人体“危险”事件。

## 6. 置信等级

- `HIGH`：两名裁决者一致，时间同步和来源满足协议；
- `MEDIUM`：事件类型一致，但某个时间点或来源存在受控不确定性；
- `LOW`：证据不足或关键时间点无法一致；只用于缺口分析，不进入主要 Gate。

正式研究中，主要事件 Gate 只接受预注册允许的置信等级；P5 建议主要分析使用高置信事件。

## 7. 盲法、撤回与审计

- 裁决者不可见模型输出；
- 真实直接身份与去标识化研究 ID 的映射只由数据控制者访问；
- 撤回 locator 能定位所有段、事件与派生物；
- 删除和保留规则以 P3 获批的数据管理计划为准；
- 敏感裁决记录、视频和批准原件不进 Git。

## 8. 停止条件

出现以下任一情况时暂停标签进入研究集：身份混淆、许可或同意不清、同步误差无法估计、裁决分歧持续过大、事件定义漂移、原始与派生记录不可追溯、撤回无法执行，或模型结果影响裁决。
