# 事件级指标规范（P0 v1）

## 1. 共同原则

指标单位首先是“事件、告警簇、参与者和连续人日”，不是平衡窗口。所有成绩必须绑定冻结合同、数据版本、参与者拆分、模型/策略哈希、执行命令、覆盖率和限制。

P2 确定性夹具生成的数值只验证公式。它们不得写成真实世界成绩。

## 2. 事件级召回

对提前量阈值 `h ∈ {1,2,3,5,10}` 秒：

```text
Recall@h = 提前量 >= h 的匹配目标事件数 / 可评估目标事件总数
```

每个时域同时报告分子、分母、点估计和 95% Wilson 区间。迟报、零提前和漏报不计入任何正提前量命中。

## 3. 事件级精确率

```text
Event precision = 匹配到目标事件的告警簇数 / 所有外显告警簇数
```

重复候选先按冻结合并规则形成告警簇。被策略抑制的候选分别在“抑制前”统计中出现，在“抑制后”不进入外显告警簇。未标注时段如何处理必须在真实研究协议中预注册；P2 夹具没有未标注时段。

## 4. AUPRC 与无技能基线

平均精确率（AP）按预测分数从高到低排序，在每个正例位置累加该位置的 precision，再除以正例总数。报告同时给出真实事件率/正例率，作为无技能参照。没有正例时 AUPRC 为不可计算，不能写成 0 或 1。

## 5. 误报/人日

```text
False alerts per person-day = 未匹配告警簇数 / 连续观察人日
```

分母必须是实际连续观察时长，不得用短脚本回放小时、平衡负窗口数或模型可评估窗口数替代。报告总人日、总体率、参与者均值、中位数、95 分位数、最大值和场景分布。缺少某个告警参与者的观察时长时，代码直接拒绝计算。

## 6. 校准

- Brier：预测分数与 0/1 结果差的平方均值；
- ECE：预注册分箱中，预测均值与实际频率差的加权绝对值；
- 后续真实研究还需报告可靠性图、校准截距/斜率，并按预测时域分别计算；
- 校准器只能在训练/验证折内拟合，不能在外层测试或外部集上调节。

## 7. 提前量分布

报告中位数、Q1、Q3、最小值、最大值、负提前量数量、零提前数量和事后比例。`t_instability` 与 `t_impact` 两套提前量必须分栏。

## 8. 覆盖率和拒判率

```text
Coverage = 可评估连续时长 / 总观察时长
Abstention = 1 - Coverage
```

可评估时长不能超过观察时长。缺失、未知活动、分布外、佩戴异常、通道缺失、时钟或质量 Gate 失败分别记录拒判原因；拒判不能计为阴性或低风险。

## 9. 迟报、漏报与撞击后报告

- `t_alert_perceivable > t_instability`：迟于首次失稳；
- `t_alert_perceivable > t_impact`：迟于撞击；
- 匹配窗口内无告警：漏报；
- 负提前量保持负值，不截断；
- 当前 P2 只实现相对 `t_instability` 的工程公式，E0 模板为 `t_impact`、端到端延迟和亚组保留必填位置，真实数据到来前不填成绩。

## 10. 抑制影响

对同一候选集分别计算：

1. 抑制前：所有候选均视作外显；
2. 抑制后：去除带明确抑制原因的候选；
3. 比较事件级召回、精确率、误报/人日、提前量、覆盖率、迟报和漏报；
4. 保存每个被抑制候选及原因。

## 11. 端到端延迟与亚组

真实研究必须实测采样、窗口等待、预处理、推理、策略、传输和设备呈现的 p50/p95/p99。还必须按年龄、性别、行动能力、辅助器具、设备、佩戴侧、地点和数据质量报告表现；样本不足时标记不可判断。

P2 不接设备、不提示用户，因此没有真实端到端延迟或亚组成绩；报告模板将这两项保留为 `not_measured_e0`。
