# 手表实时与采集使用说明（M5StickS3）

更新时间：2026-10-06

## 一、启动工作台

双击 `scripts\windows\start-early-risk-workbench.cmd`，浏览器打开 `http://127.0.0.1:8010/`。
停止使用同目录的 `stop-early-risk-workbench.cmd`。

## 二、现场演示“手表实时”（USB）

1. 确保手表已用数据线连接电脑；
2. 页面左侧点“手表实时”（或直接打开 `http://127.0.0.1:8010/#live`）；
3. 点“开始实时读取”：状态变为“已连接”，波形开始滚动；拿起手表轻轻晃动，曲线随之变化；
4. 每约 2 秒更新“当前动作候选 / 跌倒动作筛查 / 提前风险线索”与一句结论；
5. 拔掉数据线：状态显示“断线重连中”；插回后自动恢复；
6. 点“停止”结束；点“保存本次实时数据”会把本次数据保存为 `data/raw/watch/live-*.csv`。

注意：

- 实时读取期间串口被占用，不要同时运行录制工具 `record-watch.cmd`；
- 实时输出是滚动研究模型结果，不是现实报警，不发送任何通知，也不会自动写入文件。

## 三、采集真实动作数据（命名约定）

- 真人动作录制：`P` 开头，例如 `P01-走路-01`；
- 非真人的设备测试（如桌面静置）：`M` 开头，例如 `M01-静止-01`；
- 程序生成的合成数据不进入“手表实测”分类。

操作步骤：

1. 双击 `scripts\windows\record-watch.cmd`；
2. 输入名字与秒数（建议 20–30 秒）；
3. 倒计时后做动作（走路、坐下、弯腰等），完成后文件自动保存到 `data/raw/watch/`；
4. 把文件与动作清单交给后续协作者，用 `research/early_risk/import_watch_serial.py` 导入为“手表实测”案例。

## 四、对评委可以怎么说

- 平台目前共 136 条案例：公开数据 105 组 + 手机自主采集 30 组 + 手表实测 1 组（M01 设备静置测试）；
- “手表实时”演示的是真实设备 → 电脑 → 网页的在线链路；
- 所有判断都附波形与模型依据；实时与离线结果都是研究演示，不是现实报警。

## 五、手表本体怎么操作（M5StickS3）

| 操作 | 方法 | 说明 |
|---|---|---|
| 开机 / 复位 | 单击侧面按键 | 平时插着数据线就不用管它 |
| 关机 | 双击侧面按键 | 长时间不使用时可以关机 |
| 进入下载模式 | 长按侧面按键约 2 秒（内部绿灯闪烁） | 仅烧录程序时使用，日常不要长按 |
| 充电 | USB-C 线接电脑或充电头 | 内置电池 250mAh，插线时同时供电和充电 |

屏幕显示说明：

- 显示 “IMU stream / 50 Hz / samples: 数字”，且数字在不断增加 = 正在正常发送数据；
- 屏幕不亮：单击侧面按键唤醒；仍不亮就插一次数据线；
- 数字停住、屏幕卡住：插拔一次数据线，或单击侧面按键复位。

常见问题：

- 网页“手表实时”提示没有找到设备：确认数据线插好（换 USB 口或换线）、确认没有同时开着录制工具，然后先“停止”再“开始实时读取”；
- 误进下载模式（屏幕黑、绿灯闪）：插拔一次数据线，或单击侧面按键即可恢复。

注意：这块表目前只通过 USB 数据线工作，还没有做无线版本；实时演示或录制数据时必须插着线。

## 六、免插线（Wi-Fi）演示与录制

前提：手机开一个 **2.4 GHz** 热点（ESP32 不支持 5GHz；小米/华为手机在“个人热点 → 热点配置/更多设置 → 频段”里改成 2.4 GHz），电脑连接同一个热点。

首次配对（手表需用数据线连接电脑一次）：

1. 双击 `scripts\windows\connect-watch-wifi.cmd`；
2. 输入热点名称与密码，等待出现“连接成功…手表地址 10.x.x.x”；
3. 可以拔掉数据线——手表会用自带电池继续工作，并记住这个热点（重新开机也会自动连）。

演示/使用：

1. 在“手表实时”里把**数据来源**选成“Wi-Fi 无线（免插线）”，点“开始实时读取”；
2. 波形与滚动筛查照常运行，判断文字也会同步到手表屏幕（出现跌倒候选时手表会红屏提示并震动一下）；
3. 无线保存数据（命令行）：`.\.venv\Scripts\python.exe tools\watch_wifi_receiver.py --seconds 30 --name P01-走路-01`。

注意：

- 无线演示时**不要让手表贴着电脑或数据线**——实测数据线插着会明显干扰手表射频（拔线后 50 次/秒 → 插线贴电脑约 5 次/秒）；演示时手表戴在手上、离电脑半米以上即可；
- 热点名称/密码换了以后，重新跑一次 `connect-watch-wifi.cmd` 即可。

## 七、网页上的“手表控制”（双向交互）

“手表实时”区域里的“手表控制”面板（USB 与 Wi-Fi 连接时都能用）：

- **手表状态**：电量、是否充电中、无线地址（手表每 5 秒自动上报一次）；
- **发送到手表**：输入一段文字，点按钮后会显示在手表屏幕上；
- **振动提示 / 清除屏幕提示**：测试提醒通道（振动需装好振动模块）；
- **让手表连接**：在网页里直接输入热点名和密码完成配对，等价于命令行方式，配对成功后“手表状态”会显示无线地址。
