# 演示视频步骤教学（从零到成片）

更新时间：2026-10-07。适用：校赛 demo 视频 / 现场演示。

## 第 0 步 · 开录前 10 分钟准备

设备清单：

- 手表（充满电）、数据线备用、Grove 振动模块插好 Port A；
- 手机：开 **2.4 GHz** 热点（设置 → 个人热点 → 频段 → 2.4 GHz）；
- 电脑：连上手机热点 → 双击 `scripts\windows\start-early-risk-workbench.cmd` 打开平台；
- 录屏工具：**Windows 自带 Xbox Game Bar**（Win + Alt + R 开始/停止，文件存在 `此电脑 → 视频 → 捕获`）；
- 关掉无关窗口和通知（开"专注助手"），浏览器 Ctrl+加号 放大到 125–150%。

## 第 1 步 · 把平台摆成"上镜状态"

1. 打开 `http://127.0.0.1:8010/`；
2. 左侧"手表实时" → 数据来源选 USB 或 Wi-Fi 无线 → 点"开始实时读取" → 确认：**已连接 / ≈50 次每秒 / 电量**；
3. 把"自动停止"设为 **30 秒**；
4. 手表戴在左手腕（护腕/魔术贴固定），**离电脑半米以上**，屏幕朝镜头；
5. 桌上摆好手机（可见热点开着），画面里留出手表。

## 第 2 步 · 录屏操作方法（Game Bar）

- 按 **Win + Alt + R** 开始录制 → 右上角出现计时条 → 再按一次停止；
- **一次只录一个镜头**（20–90 秒）；哪条不满意就单独重录，最后拼接；
- 鼠标动作放慢：点一个按钮 → 停 1 秒 → 再做下一步。

## 第 2.5 步 · 双机位怎么配合（电脑录屏＋手机）

**分工一句话**：电脑录屏 = 软件证据（界面、图表、结论）；手机 = 实物证据（人、手表、红屏、振动、动作）。

### 手机机位设置
- **横屏拍摄**（和录屏一样 16:9，后期好拼）；
- 用支架/靠墙固定在**人的侧前方 45°**，距离 1.5–2 米，能同时拍到上半身和手腕；
- **长按屏幕锁定曝光/对焦**（AE/AF 锁定）；房间光线均匀，别背光；
- 手机开**勿扰模式**，避免来电打断；
- 拍手表屏幕特写时：靠近到 15–20 厘米，**斜一点角度**避免反光。

### 两个机位的分工表
| 镜头 | 用哪台 | 拍到什么 |
|---|---|---|
| 开场 / 案例回放 / 新数据检测 | 电脑录屏 | 工作台界面与结论 |
| 手表实时演示 | 电脑录屏（主画面）＋手机（画中画） | 屏幕：波形与红横幅；手机：戴表走动、手表红屏＋振动 |
| 现场采集登记 | 电脑录屏（主画面）＋手机（特写） | 登记结果；手表佩戴特写 |
| 收尾 | 电脑录屏 | 边界声明 |

### 两机同步技巧
- 每个分段开始时：**对着镜头拍一下手**（或把手表举到手机镜头前晃一下）→ 剪辑时凭这个"标记"对齐两条素材；
- 也可以录屏时让手机同时拍着屏幕，靠声音对齐。

### 剪辑（剪映专业版）五步
1. 新建项目 → 先把**电脑录屏拖到主轨道**（它是骨架）；
2. **手机素材拖到画中画轨道**，按标记对齐；
3. 手机画面缩到右下角（约 1/4 大小）；关键段（手表红屏/振动）把手机画面放大到全屏 2–3 秒再缩回去；
4. 智能字幕 → 对照第 3 步台词微调；
5. 配乐音量 ≤10%，导出 1080p / 30fps。

## 第 3 步 · 分镜拍摄顺序（逐镜教学）

### 镜头 1 · 开场（约 30 秒）
- 操作：停在样本总览页，鼠标慢慢划过案例总数和"自主采集 30 / 约30组"；
- 台词："这是智能手表风险评估工作台：105 组公开腕部数据、30 组自主采集，加上正在运行的真实手表。"

### 镜头 2 · 案例回放（约 60 秒）
- 操作：点一条公开跌倒案例 → "开始检测" → 六步流程跑完 → 展示结论和波形依据；
- 台词："每条判断都有六步依据，三个模型独立输出，不合成一个分数。"

### 镜头 3 · 手表实时（约 90 秒，重头戏）
- 操作：开始实时读取 → 正常走几步（波形平稳）→ **快速晃动手臂** → 网页红横幅 + 手表红屏"跌倒风险预警" + 振动 → 停下等 10 秒让它清零 → 用"手表控制"发一句话到表屏、点"振动提示"；
- 台词："这是手表此刻的真实数据。出现风险预警时，网页和手表同时提醒。"

### 镜头 4 · 现场采集一条（约 60 秒）
- 操作：把"自动停止"设 30 秒 → 开始实时读取 → 做"走路" → 自动停止并保存 → 看总结 → 点"登记" → 回"样本总览 → 手表实测"点开这条；
- 台词："刚才这段就是现场采的，已经登记成案例，随时能回放复核。"

### 镜头 5 · 收尾（约 30 秒）
- 操作：拖一个 CSV 进"新数据检测"跑一遍；
- 台词："任何新传感器文件都能跑同一套六步流程。它是工程演示：不发送真实报警，也不做医疗承诺。"

## 第 4 步 · 拼接与导出

1. 用**剪映专业版**（免费）：新建项目 → 按顺序导入 5 段 → 每段掐头去尾；
2. 可选：文本 → 智能字幕（自动生成中文字幕）；
3. 导出 1080p，命名 `智能手表风险预测_演示视频_v1.mp4`；
4. 成片建议 3–5 分钟；配背景音乐的话音量压到 10% 以下，不要盖过人声。

## 第 5 步 · 录完自查清单

- [ ] 画面清晰、文字看得清；
- [ ] 声音正常（无电流声、无回声）；
- [ ] 五个镜头齐全：开场 / 案例回放 / 手表实时 / 现场采集 / 收尾；
- [ ] "跌倒风险预警"红屏 + 振动 的镜头拍到了（多拍一条备用）；
- [ ] 结尾明确说了"工程演示、不发送真实报警"；
- [ ] 视频文件另存一份备份。

## 常见问题

| 问题 | 处理 |
|---|---|
| 录出来没声音 | 设置 → 游戏 → 捕获，确认勾选麦克风；或先用 30 秒试录检查 |
| 手表连不上 | 热点是否 2.4GHz；手表离电脑太远/太近；电量是否过低 |
| 某镜头不满意 | 只重录那一段即可，不影响其他素材 |
| 想改台词 | 先照稿录一遍，剪映里可以只换字幕不动画面 |
