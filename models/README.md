# 模型接入目录

这里统一放置四个研究模块的 manifest（模型身份证）、小型模型/规则文件和版本说明；既有适配器位于 `backend/app/models/`，公开代理提前风险运行时位于 `research/early_risk/public_risk_model.py`。

四个独立研究模块均已接入：跌倒检测使用固定 ONNX 并在 100 个来源案例上完成同源行为重放；长期规律异常使用固定种子 100 天合成事件和确定性统计规则；活动识别使用 CAPTURE-24 恢复前缀子集的 24 人训练组和 12 人不重叠评估组训练并导出 ONNX；提前风险公开代理基线使用 WEDA 1 秒因果六轴窗口和参与者隔离划分，保存 1/2/3 秒三个加权逻辑回归头。四者均未完成外部验证，均不获部署批准。

硬边界：

- 跌倒检测只接受真实存在的 `200×6` 六轴窗口；缺少陀螺仪时不能补零进入该模型；
- 规律异常首版明确使用 100 天 `SYNTHETIC_ROUTINE` 合成生活事件；
- 活动识别使用真实 `400×3` 腕部加速度窗口并输出活动候选；CAPTURE-24 来源是逐成员核验的 48 人恢复前缀子集，不是完整 151 人数据包，也不是老人专项数据；
- 提前风险基线的时间标签只是 WEDA 数据集跌倒区间开始代理锚点，不是现实 `t_instability`；P01 自主采集30组已完成冻结模型工程验证，但只有一名参与者，不能证明现实预测或跨人群泛化；
- 四项输出独立显示，不计算未经校准的综合医学风险；
- 未完成外部验证的模型必须保持 `deployment_approved=false`。
