# 模型接入目录

这里将统一放置三个模型的接入适配器、manifest（模型身份证）、推理接口和版本说明。

模型一是跌倒检测，模型二是长期规律/异常检测，模型三是活动识别。统一输入输出和 manifest 合同已定义在 `backend/app/contracts.py`，但当前仍未复制模型文件、注册 manifest 或执行任何推理。

硬边界：

- 跌倒检测只接受真实存在的 `200×6` 六轴窗口；缺少陀螺仪时不能补零进入该模型；
- 规律异常首版明确使用 100 天 `SYNTHETIC_ROUTINE` 合成生活事件；
- 活动识别使用 `400×3` 腕部加速度窗口并输出活动候选；
- 三个输出独立保存，不计算未经校准的综合医学风险；
- 未完成外部验证的模型必须保持 `deployment_approved=false`。
