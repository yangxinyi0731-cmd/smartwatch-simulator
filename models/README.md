# 模型接入目录

这里统一放置三个模型的 manifest（模型身份证）、小型模型/规则文件和版本说明；Python 适配器位于 `backend/app/models/`。

三个独立研究模型均已接入：跌倒检测使用固定 ONNX 并在 100 个来源案例上完成同源行为重放；长期规律异常使用固定种子 100 天合成事件和确定性统计规则；活动识别使用 CAPTURE-24 恢复前缀子集的 24 人训练组和 12 人不重叠评估组训练并导出 ONNX。三者均未完成外部验证，均不获部署批准。

硬边界：

- 跌倒检测只接受真实存在的 `200×6` 六轴窗口；缺少陀螺仪时不能补零进入该模型；
- 规律异常首版明确使用 100 天 `SYNTHETIC_ROUTINE` 合成生活事件；
- 活动识别使用真实 `400×3` 腕部加速度窗口并输出活动候选；CAPTURE-24 来源是逐成员核验的 48 人恢复前缀子集，不是完整 151 人数据包，也不是老人专项数据；
- 三个输出独立保存，不计算未经校准的综合医学风险；
- 未完成外部验证的模型必须保持 `deployment_approved=false`。
