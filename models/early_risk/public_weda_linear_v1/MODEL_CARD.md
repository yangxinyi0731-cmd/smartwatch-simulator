# 公开 WEDA 1/2/3 秒代理提前风险基线 v1

## 用途

这个模型用于校赛研究演示：对 50 Hz 六轴腕部 IMU 的每个 1 秒因果窗口，分别输出“按 WEDA 受控数据模式，未来 1、2、3 秒内是否接近数据集跌倒区间开始”的三个研究分数。

它不是现实意外跌倒预测器，不是医疗模型，不得触发现实报警。

## 输入与输出

- 输入：`[batch, 50, 6]`；通道依次为 `ax,ay,az,gx,gy,gz`；
- 单位：`m/s²` 与 `rad/s`；
- 上下文：当前时刻之前 1 秒，不读取未来样本；
- 输出：1 秒、2 秒、3 秒三个分数；
- 运行时保证 `score_1s <= score_2s <= score_3s`，因为更长时间范围包含更短时间范围；
- 每个头使用校准参与者单独选择的关注阈值。

## 数据与划分

来源是固定版本 WEDA-FALL 的本机处理文件。正例来自参与者在床垫环境中的受控模拟跌倒；日常活动作为负例。训练、阈值校准、最终评估使用互不重合的参与者，详细 ID、案例数、窗口数、指标和哈希见 `manifest.json` 与 `reports/early_risk/public_weda_linear_v1.json`。

时间标签只能称为 `WEDA_FALL_INTERVAL_START`（数据集跌倒区间开始代理锚点）。它不是经专家判定的真实 `t_instability`。

## 特征和模型

模型对六个方向轴、加速度合量、角速度合量及其变化量提取均值、标准差、极值、范围、RMS、分位数、前后半窗变化和轴间相关等确定性特征。三个加权逻辑回归头只用训练参与者拟合；均值与标准差也只来自训练组。阈值只用校准组选择，最终评估组不参与训练和阈值选择。

模型保存为版本化 JSON 数组，由 `research.early_risk.public_risk_model.PublicEarlyRiskModel` 使用 NumPy 运行，便于后续将同一特征、标准化和线性参数迁移到移动端或手表端实现。

## 关键限制

1. 受控模拟跌倒与现实意外跌倒存在明显域差异；
2. 数据集区间开始不等于真实失稳开始；
3. P01 自主采集30组已用于冻结模型工程验证，但这些记录只来自一名匿名参与者，且没有用于训练或调参；
4. 当前没有外部数据集验证、前瞻静默试运行或真实手表验收；
5. P01 工程验证暴露了大幅度摆臂和走路造成的候选误判，仍需更多参与者和长期自然活动复核；
6. `deployment_approved=false`、`real_world_prediction_evidence=false`。

## 重复训练

```powershell
.\.venv\Scripts\python.exe -m research.early_risk.train_public_risk_baseline
```

训练命令会同时覆盖 `model.json`、`manifest.json` 和评估报告，并在最后重新加载保存模型执行烟雾测试。
