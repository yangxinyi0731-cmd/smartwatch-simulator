# 数据来源登记

统一来源合同已经建立，导入工具会在这里保存可读的来源清单，并同步写入 SQLite：来源网址、固定版本、许可证状态、许可依据、是否允许重新分发、选择规则、原始文件哈希、处理文件哈希、质量标记与真实标签。

`weda_fall_100_v1.json` 是已实测导入的 100 条独立来源记录目录：40 条年轻参与者受控床垫模拟跌倒、30 条老年参与者受控日常活动、30 条年轻参与者受控日常活动。它不是“100 个真实老人跌倒”；老人记录中没有跌倒标签。

目录不包含传感器数组。原始与处理后的传感器文件只保留在本机 Git 忽略目录，因为上游仓库没有可确认的开源许可证。处理文件可由固定 Git 提交和导入命令重新生成。

WEDA-FALL 上游在 2026-08-28 的 GitHub API 中没有可识别许可证；CAPTURE-24 返回 `NOASSERTION`。两者在许可进一步核验前都不能仅凭“公开下载”判定可重新上传或商用。

`capture24_recovered_prefix_v1.json` 记录一次官方大文件下载中断后的保守恢复结果：只把 48 个已经完整写入、解压长度和 CRC-32 均通过的参与者成员连同元数据写入新的有效 ZIP；截断的 P008 和其后未知成员全部排除。恢复 ZIP 和原始失败前缀都留在 Git 忽略目录，目录文件明确说明这不是完整 151 人数据包。

CAPTURE-24 数据许可另由 2024 年 Scientific Data 论文和 Oxford Research Archive 声明的 CC BY 4.0 核验；这不改变其 GitHub 工具代码的独立学术许可证，也不等于应把 2.35 GB 恢复数据提交到本仓库。
